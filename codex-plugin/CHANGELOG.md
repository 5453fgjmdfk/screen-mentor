# 屏幕伴学版本日志

## v0.14.0 · 2026-11-22

- 单击桌宠或聊天图标即可在人物旁快速发消息。每位学伴的长期会话并入管理面板，快速聊天和会话共用同一份本机记录。
- 等待回复时播放思考动作。兼容流式接口的回复同步显示在人物气泡和会话里，完整文字存入本机档案。桌宠也可从悬停按钮直接编辑各自的外观。
- 根据实际动画帧可见像素判断贴边。拖拽时允许气泡暂时越出屏幕，人物碰到左、右或底部后松手才进入探头。开始屏幕伴学时收起快速输入并停止显示日常回复。

## v0.13.0 · 2026-11-22

- 桌宠外观整合到管理面板，可为每位桌宠独立设置皮肤与气泡色。保留方案、动画预览、GIF 导入、精灵图裁剪和原有打开入口。
- 「并行协作」由主学伴拆分任务，最多三位子成员同时处理，再由主学伴汇总。子成员失败时可汇总其余结果，停止后忽略在途回复并停止后续步骤。
- 日常对话支持把当前草稿带到群聊；普通发送与实时屏幕伴学继续由主学伴处理。开始伴学会暂停桌面闲聊并停止后台协作。

## v0.12.0 · 2026-11-22

- 新增 Windows 管理面板，集中查看伴学状态和管理群聊、成员、模型、外观及记忆。桌面快捷方式、托盘和 Codex 都能打开。
- 成员可配置分工、模型和皮肤，单独保存私聊与记忆。群聊支持点名和按分工逐位协作，可随时停止后续回复。
- 同时显示多个可拖动、可贴边的桌宠。定期闲聊默认关闭，开启后轮换选择两位可见的伙伴，用气泡显示短对话。
- 屏幕伴学接管时收起其他桌宠并暂停群聊，结束后恢复桌面模式。当前桌面功能沿用兼容 Chat Completions 的模型接口。

## v0.11.2 · 2026-11-22

- 应用图标改用石板蓝底、取景角和高亮控件组成的抽象标记。图标与角色皮肤可独立使用。

## v0.11.1 · 2026-11-22

- 提供 Windows 安装 ZIP。桌面学伴和 Codex 插件有独立的双击安装入口。
- 桌面程序按版本安装，保留回退所需的程序文件；账户下的对话、记忆和换肤设置继续共享。
- 增加原创龙角与取景框图标，应用于桌面快捷方式、托盘和窗口。

## v0.11.0 · 2026-11-22

- 新增独立常驻的 Windows 桌面学伴，复用角色、外观管理和引导。Codex 通过当前 Windows 用户的本地连接接管，结束或重连超时后自动回到日常模式。
- 日常原文与长期记忆持久化到 SQLite。使用中文及英文关键词检索、带字节预算的历史选取、不联网的手动记忆与找回。普通聊天在同一次模型回复中提取有原文出处的候选记忆。
- 常驻模型可配置本地或兼容 Chat Completions 的 HTTPS 接口，桌面应用可独立于 Codex 安装。

## v0.10.1 · 2026-11-22

- 内置窗边小龙的侧边和底部探头新增眨眼。实际浮窗和外观预览采用同一组眼部帧。

## v0.10.0 · 2026-11-22

- 外观预览同步播放侧边与底部探头。两处支持自带 GIF 帧动画，PNG 仍可用。
- 左栏可保存角色素材与气泡配色的组合。气泡支持五种预设色和自定义 RGB。
- 制作皮肤时可悬停查看分栏规格，直接导入 GIF，或通过拖框与像素输入裁剪透明 PNG 精灵图。支持按行列生成循环动画。

## v0.9.0 · 2026-11-21

- 新增「伴学外观」管理器。可在原聊天中打开、从角色悬停菜单打开，也可以从桌面独立启动。
- 提供站姿动画、贴边探头和气泡配色预览。支持三种配色、自制皮肤、导入 ZIP，以及恢复默认。
- 两个入口共用本机外观设置。应用后，正在运行的伴学角色和气泡会随之更新。

## v0.8.1 · 2026-11-21

- 左右边缘播放扶边探头动画，底部播放双手撑边、向上冒头的动画。可贴靠左右两侧和底部。
- 探头时保留小型思考气泡，侧面朝屏幕内侧显示，底部向上显示。实时更新伴学状态或当前思考小结，并且可点穿。

## v0.8.0 · 2026-11-21

- 把小龙或输入框标题拖到屏幕任一边，松手后气泡和按钮会收起，只露出一小块动态探头。
- 点击探头或把它往屏幕里拖，即可展开气泡和控件。也可沿边缘滑动探头，避开需要操作的区域。
- 探头状态下继续更新当前伴学提示，屏幕上的穿透标注照常显示。

## v0.7.5 · 2026-11-17

- 文本复制区的「要输入的内容」标题可拖动整个伴学窗。正文可正常选择，复制按钮独立响应。

## v0.7.4 · 2026-11-17

- 将 Windows 窗口截图放入独立进程，请求超过 2.5 秒时结束旧进程，再由下一次请求新建。
- 读图失败或练习窗离开前台时清除旧的判断计时，恢复后以新画面继续。
- 按住小龙拖动浮窗，可在显示器之间移动。

## v0.7.3 · 2026-11-17

- 小龙气泡可按「已看到」「正在核对」「判断小结」更新。每条小结到达即显示，保留最新的一条，进入下一步时由新指引接替。
- 新画面、暂停和结束继续按伴学原流程处理，带有旧截图编号的小结会被拒绝。

## v0.7.2 · 2026-11-17

- 磨砂渐变和细亮边只绘制在图标本体，悬停时提亮图标。
- 暂停、答疑、停止图形统一为 12 逻辑像素高。缩小问号，停止保持实心。

## v0.7.1 · 2026-11-17

- 人物下方的操作入口改为三个半透明白色图标。双竖线暂停、问号答疑、实心方块停止。
- 暂停后显示播放三角，点击可继续。鼠标悬停在图标上时提供文字说明。

## v0.7.0 · 2026-11-17

- 将右下角练习面板换为透明小龙伴学窗，使用美术包 v0.2.1 的四组循环。状态、进度与可以公开的观察摘要放在人物上方气泡。
- 人物悬停时露出「暂停」「答疑」「结束」。鼠标在按钮区域时保持显示，移开后收起。
- 协调气泡、半透明按钮、屏幕框选与鼠标示范的淡紫配色。保留输入内容复制、答疑图片和点击或拖动后的收起行为。

## v0.6.1

- 操作完成后收起屏幕标注。读取及判断进度显示在右下角面板。
- 反馈对话框居中，并支持粘贴图片。
