# 屏幕伴学 · Codex Windows 插件

在原来的学习聊天中继续实操。伴学工具把指定窗口的画面变化和你在面板报告的问题返回给当前聊天，由当前聊天用已有的学习内容判断下一步并画穿透标注。

## 安装

发布包解压后，双击根目录的 `install-desktop.cmd` 只装桌面学伴，或双击 `install-codex.cmd` 同时注册 Codex 插件。首次安装需 Python 3.11+，安装过程会下载 Python 依赖。桌面应用可以独立使用。

需要 Windows 上的 Codex 桌面版和 Python 3.11+。先打开 Codex，在本目录的 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本会把本地运行环境放在 `%LOCALAPPDATA%\ScreenMentor`，然后把「屏幕伴学」注册到 Codex。原版浮标无需启动。

首次安装或升级后，完全退出并重新打开 Codex。插件目录里的本地来源是「Screen Mentor Local」。回到已有的学习聊天，告诉 Codex 对哪个窗口开始实时伴学。

## 桌面学伴

桌面的「屏幕伴学 - 桌面学伴」可以独立打开。只安装桌面应用时，在插件目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1 -DesktopOnly`。

- 在「模型」页可编辑默认配置，也可选择任意学伴。学伴可沿用默认接口并覆盖模型名，或勾选「使用独立接口」单独填写兼容 Chat Completions 的接口地址和模型名。可用 HTTPS 或本机 HTTP，例如 `http://127.0.0.1:11434/v1`。
- 接口需要密钥时，填已设置的环境变量名，再重新启动学伴。独立接口的变量名留空时不发送密钥。私聊、群聊、定时任务和并行协作分别使用参与者配置的模型接口和用量。Codex 屏幕伴学继续使用发起伴学的对话。
- 日常对话、手动记忆和学习小结保存在用户目录的 `.codex/screen-mentor/agent.sqlite3`。输入「记住：…」可以立即保存一条用户确认的记忆；「回忆：关键词」可以离线找回相关原文。模型提取的候选记忆可以在「长期记忆」确认或移出。
- 发给模型的是预算内的最近对话、已确认的记忆和检索到的原文片段。需要核对旧细节时可再检索一次。完整原文在本机保留，模型请求的历史部分按字节控制大小。
- Codex 或其他能调用本地 MCP 的 Agent 可通过 `scripts/bridge.py` 接入。开始实时伴学后，同一个浮窗会把屏幕反馈和问题送回本场对话；结束或短暂重连超时后回到桌面学伴。伴学图片不写入日常记忆，用户主动要求保存的小结可进入本机学习档案。

## 管理面板与桌宠群聊

从桌面「屏幕伴学 - 桌面学伴」、托盘的「管理面板」打开，也可以在 Codex 里说「打开伴学管理面板」。

- 单击人物或悬停时的聊天图标，可在桌宠旁输入消息。「打开会话」会进入管理面板。管理面板的「会话」页也可切换不同学伴，查看私聊记录或长期记忆。
- 等待首段回复时播放思考动画。模型提供流式响应时，气泡和会话会逐段更新，长回复可在会话里查看全文。自制皮肤可导入 `thinking.gif`。
- 在「成员」添加伙伴或点「编辑档案」，给每位学伴填写职责、性格、表达方式和角色背景。这些设定会用于该成员的日常对话、房间发言和任务协作。最多保存八位成员。成员的模型、私聊记录和长期记忆分别管理。
- 创建时可选本机已有的动画皮肤，或导入一张透明 PNG 作为静态桌宠。PNG 不超过 8 MB，边长不超过 4096 px，程序会裁去透明边缘并缩放后生成站姿和探头。完整状态动画继续在「外观」页导入。勾选「在桌面显示这个伙伴」可立即启用对应桌宠。
- 在 Codex 中可说「添加一个叫纸鹤的学伴，性格温和，负责把实验步骤整理成检查清单，并显示在桌面」。Codex 通过 `create_member` 创建，支持指定已有皮肤或使用明确提供的本机 PNG 路径。仅要求设计人设时可先讨论设定。
- 在「群聊」点击成员行即可选择或取消参与者，浅色表示选中。普通消息也支持 `@成员名称`，名字后留一个空格即可接着输入。每轮最多四位发言。「接力讨论」让成员依次给出意见。
- 复杂任务可点「并行协作」。主学伴自动参与并给勾选的子成员分工，最多三位子成员同时处理，最后由主学伴汇总可用结果并指出仍待验证的部分。这一轮最多发出五次模型请求。日常对话里的「协作…」可把输入框中的任务带过去。子成员参与文字协作，屏幕伴学仍由当前 Codex 对话负责。
- 在「闲聊」可建立不同房间。房间可以勾选成员，或跟随桌面上当前可见的伙伴。可以填写房间提示，并选「双人轮换」「全组依次发言」或「主持人先发言」。每个房间分别保存消息，切换房间时保留各自的草稿。输入 `@成员名` 后加空格即可点名，`@all` 发给全组，每轮最多四位发言。
- 在「房间设置」每行填一个自定义话题，最多 30 条，每条最多 120 字。「聊一次」会按顺序取出下一条话题，留空时使用内置话题。可指定一间房间按 15–240 分钟间隔定时闲聊。伴学或已有对话尚未完成时会跳过本轮闲聊。
- 群聊历史在本机保存。各成员的私聊与记忆分开保存，群聊请求只使用公共群聊内容，定期闲聊只使用当前房间记录和话题。每位发言者会用各自配置的接口发起有输出上限的模型请求。

## 定时任务与托盘

- 在「定时任务」新建任务，填写要发送给学伴的问题或工作要求、首次执行时间和频率。可以选主学伴处理，或由主学伴带当前启用的最多三位子成员并行处理。任务生成文字结果，可从该页查看最近一次，也可在群聊里回看。
- 任务按电脑本地时间运行。伴学、私聊或群聊占用时延后。退出应用期间错过的任务，会在下次启动且空闲时执行一次，重复计划随后恢复正常频率。每轮失败会注明原因，重复计划在下一个设定时间继续。
- 鼠标悬停在桌宠上时，可点面板图标打开管理面板，或点减号隐藏桌宠。从「桌面」页或托盘图标的右键菜单可重新显示。隐藏时后台工作继续运行。需要退出应用时可用托盘菜单，或按「设置」选择的面板关闭行为操作。
- 在「设置 → 外观」选预设、输入 HEX 或打开选色器，管理面板配色会立即更新并保存。「通用」可设置关闭按钮行为，「桌宠」可配置启动可见、贴边探头和回复气泡停留时间。「工作空间」可设工作目录、启动页及是否记住窗口位置和大小。

## 体验

> 用屏幕伴学，接着刚才讲过的内容，带我到 Proteus 里实操。

窗口标题有多个匹配时，选定你要练习的那个。把要标注的按钮露出来。标注不拦截鼠标。新画面出现时先撤下旧标注，模型根据稳定后的画面给下一步。

伴学期间聊天需要保持在运行。软件里可以用「暂停」「遇到问题」「结束」。退出 Codex 或停止当前回合会中断伴学，桌面学伴仍可使用。仅观察选定的前台窗口及其对话框，新画面会作为工具结果进入当前聊天。插件不另写截图文件。模型识别通常需要数秒。弹出式独立菜单、受保护内容和个别硬件加速界面可能无法截图。

指向文本输入框时，附近保留卡片和箭头，输入区不画框线。右下角面板的「要输入的内容」支持选中复制，也可点「复制」后回软件粘贴。「遇到问题」可勾选最近一次练习窗口截图，文字可选，反馈发回当前聊天。

点击和拖动用穿透的鼠标图标示范，拖动落点用圆圈标出。快捷键在软件上方显示组合键及用途。普通桌面软件重开或切换到新窗口时会自动跟随。跨软件练习在启动时指定需要跟随的软件。空闲或标注遗失时会限频重新检查，也会尝试本地恢复有效标注。

原聊天停止接收画面两分钟后会暂停抓图和清除指引，再给原聊天一分钟重连。结束或超时后恢复桌面学伴。回到原聊天继续时，以当前软件界面重新接入。

按住桌宠或「要输入的内容」标题可移动浮窗。等人物本体碰到左侧、右侧或底部后松手，就会切换成探头动作。贴边时，小气泡继续显示当前状态、思考小结或聊天回复，鼠标可以点穿气泡。单击探头可展开，沿边拖动可调整位置，按住向屏幕内拖会直接把桌宠提起并跟随鼠标。贴边时伴学和屏幕标注照常运行。

窗口截图超时时会自动重试，气泡会显示读图状态。

完成标注的点击或拖动后，画面上的标注会收起，右下角的小龙气泡保留当前指令，并显示读图、判断和简短观察进度。鼠标移到角色上会显示暂停、答疑、外观和停止图标，暂停后点播放三角继续。反馈窗口会在屏幕中央打开，可直接用 Ctrl+V 粘贴图片，也可勾选最近一次练习截图。

## 换肤

- 打开管理面板的「外观」页，或用聊天、桌面「屏幕伴学 - 外观管理」快捷方式及角色的衣服图标直达该页。
- 在页面顶部选择桌宠。左侧选择本地外观方案，右侧播放站姿、侧边和底部探头动画。可分别更换角色素材和气泡配色，点「保存为方案」可保留当前组合，点「应用到桌宠」只更新当前桌宠。恢复初始外观时，点「恢复默认」再应用。
- 气泡可以选薰衣草、薄荷绿、雾蓝、暖桃、石墨灰，或用「自定义 RGB」输入颜色。程序会根据背景自动切换文字明暗。
- 点「制作皮肤」后，悬停任一素材栏可查看格式和尺寸。站姿、侧边和底部都支持直接导入 GIF。也可选择透明 PNG 精灵图，框选第一帧，再设置行数、列数和帧率。帧按从左到右、从上到下播放，网格紧密排列。单帧动画的裁剪可将行列都设为 1。
- 推荐单帧尺寸分别是站姿 192 × 192、侧边 144 × 192、底部 192 × 156 px。站姿人物居中，侧边扶手贴近左边，右侧会镜像。底部双手贴近底边。

皮肤与设置存放在用户目录的 `.codex/screen-mentor/appearance`，两种入口共用。换肤作用于角色和思考气泡，原有屏幕框选仍独立工作。

### 皮肤包 ZIP

ZIP 根目录放置以下文件：

| 文件 | 用途 |
| --- | --- |
| `skin.json` | 皮肤名称、格式版本和初始气泡配色 |
| `idle.gif` | 常驻站姿动画，建议设置循环 |
| `side.gif` 或 `side.png` | 左侧扶边动画或静态姿势，右侧自动镜像 |
| `bottom.gif` 或 `bottom.png` | 底部撑边动画或静态姿势 |
| `reading.gif`、`thinking.gif`、`ready.gif` | 可选，分别对应读图、思考、指引就绪。省略时沿用站姿动画 |

```json
{"version": 1, "name": "我的皮肤", "palette": "lilac"}
```

`palette` 可填 `lilac`、`mint`、`blue`、`peach`、`gray` 或 RGB 十六进制颜色，例如 `"#3F556B"`。

- 素材文件 ≤ 8 MB，最终单帧边长 1–1024 px，同一动画 ≤ 180 帧，所有帧合计 ≤ 2800 万像素。
- PNG 精灵图需要透明背景，源图长宽均 ≤ 4096 px。裁剪可使用 1–30 FPS。生成 GIF 时透明度会转换成全透明或全不透明。
- 皮肤包压缩前后都需 ≤ 32 MB。透明 PNG 素材与旧版皮肤包仍可使用。
