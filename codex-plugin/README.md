# 屏幕伴学 · Codex Windows 插件

在原来的学习聊天中继续实操。伴学工具把指定窗口的画面变化和你在面板报告的问题返回给当前聊天，由当前聊天用已有的学习内容判断下一步并画穿透标注。

## 安装

需要 Windows 上的 Codex 桌面版和 Python 3.11+。先打开 Codex，在本目录的 PowerShell 运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本会把本地运行环境放在 `%LOCALAPPDATA%\ScreenMentor`，然后把「屏幕伴学」注册到 Codex。原版浮标无需启动。

首次安装或升级后，完全退出并重新打开 Codex。插件目录里的本地来源是「Screen Mentor Local」。回到已有的学习聊天，告诉 Codex 对哪个窗口开始实时伴学。

## 体验

> 用屏幕伴学，接着刚才讲过的内容，带我到 Proteus 里实操。

窗口标题有多个匹配时，选定你要练习的那个。把要标注的按钮露出来。标注不拦截鼠标。新画面出现时先撤下旧标注，模型根据稳定后的画面给下一步。

伴学期间聊天需要保持在运行。软件里可以用「暂停」「遇到问题」「结束」。退出 Codex 或停止当前回合会中断伴学。仅观察选定的前台窗口及其对话框，新画面会作为工具结果进入当前聊天。插件不另写截图文件。模型识别通常需要数秒。弹出式独立菜单、受保护内容和个别硬件加速界面可能无法截图。

指向文本输入框时，附近保留卡片和箭头，输入区不画框线。右下角面板的「要输入的内容」支持选中复制，也可点「复制」后回软件粘贴。「遇到问题」可勾选最近一次练习窗口截图，文字可选，反馈发回当前聊天。

点击和拖动用穿透的鼠标图标示范，拖动落点用圆圈标出。快捷键在软件上方显示组合键及用途。普通桌面软件重开或切换到新窗口时会自动跟随。跨软件练习在启动时指定需要跟随的软件。空闲或标注遗失时会限频重新检查，也会尝试本地恢复有效标注。

原聊天停止接收画面两分钟后会暂停抓图。回到原聊天说「继续伴学」，即可接回仍开着的面板，并以当前软件界面为准继续练习。

按住小龙或「要输入的内容」标题可移动浮窗。拖到屏幕左侧或右侧松手，小龙会扶着边缘探出头；拖到底部时会双手撑边抬头。贴边时，小思考气泡跟着角色，实时显示当前状态或思考小结，鼠标可以直接点穿气泡。点击小龙或往屏幕里拖即可展开，也可以沿边拖动来调整位置。贴边时伴学和屏幕标注照常运行。

窗口截图超时时会自动重试，气泡会显示读图状态。

完成标注的点击或拖动后，画面上的标注会收起，右下角的小龙气泡保留当前指令，并显示读图、判断和简短观察进度。鼠标移到角色上会显示暂停、答疑、外观和停止图标，暂停后点播放三角继续。反馈窗口会在屏幕中央打开，可直接用 Ctrl+V 粘贴图片，也可勾选最近一次练习截图。

## 换肤

- 在聊天里说「打开伴学外观」，或悬停角色，点衣服图标。
- 双击桌面「屏幕伴学 - 外观管理」可单独编辑。这个入口不需要打开 Codex、开始伴学或选择练习窗口。
- 左侧挑皮肤，右侧预览站姿动画、侧边和底部探头。可以为每套皮肤选择气泡配色，点击「应用」保存。想恢复初始外观时，点「恢复默认」再应用。
- 点「制作皮肤」可直接选择站姿 GIF、左侧扶边 PNG 和底部撑边 PNG。两张 PNG 需带透明背景。左侧素材的抓握点贴近图片左边，右侧会镜像；底部素材的双手贴近图片底边。角色会使用同一套贴边动画。

皮肤与设置存放在用户目录的 `.codex/screen-mentor/appearance`，两种入口共用。换肤作用于角色和思考气泡，原有屏幕框选仍独立工作。

### 皮肤包 ZIP

ZIP 根目录放置以下文件：

| 文件 | 用途 |
| --- | --- |
| `skin.json` | 皮肤名称、格式版本和初始气泡配色 |
| `idle.gif` | 常驻站姿动画，建议设置循环 |
| `side.png` | 左侧扶边关键姿势，程序生成左右贴边效果 |
| `bottom.png` | 底部撑边关键姿势 |
| `reading.gif`、`thinking.gif`、`ready.gif` | 可选，分别对应读图、思考、指引就绪。省略时沿用站姿动画 |

```json
{"version": 1, "name": "我的皮肤", "palette": "lilac"}
```

`palette` 可填 `lilac`、`mint` 或 `blue`。图片边长最大 1024 像素，每个素材文件最大 8 MB，皮肤包原始及解压后的总量最大 32 MB。
