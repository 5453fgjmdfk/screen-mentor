# 鲸鱼娘 · 海雾蓝

本皮肤是社区「蓝色大肥鱼 / DeepSeek 鲸鱼娘」的非官方 Q 版同人改编。

- 原角色「溟月」由上善无形创作。 [原作](https://www.bilibili.com/opus/1231977657712771073)
- 女仆鲸鱼娘由 ZipZipPipe 二次设计。重绘参考为《大AI和小AI们》约 00:05 的画面。 [原视频](https://www.bilibili.com/video/BV1tE9XBbErS/) · [作者的许可声明](https://www.bilibili.com/opus/1247156596114456581)
- 屏幕伴学将其重绘为桌宠比例，补画读图、思考、侧边和底部探头及眨眼姿势，并制作六组透明循环动画。

本目录的鲸鱼娘 PNG 和 GIF，以及根目录 `tools/whale-maid/` 下的鲸鱼娘图像原稿，采用 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/deed.zh-hans)。非商业分享请保留署名、作品来源和许可，注明改动。公开分发改编作品时请采用相同许可。仓库代码（含构建脚本）采用 MIT。

使用 Pillow 运行 `python tools/whale-maid/build_whale_gifs.py` 可从同目录的三张原始生成图复现素材。四组站姿为 256 × 256，侧边探头为 190 × 250，底部探头为 256 × 214。
